FCS replacement plan v0
=======================

Goal
----

Build a lab-native thresholding path that can replace the FCS Express threshold workflow without forking the viewer. There should be one threshold runtime and one viewer product. DAS and standalone entry paths differ only in IO/setup.

Core contracts
--------------

- Saved numeric thresholds are always raw expression values.
- Display transforms are visual only.
- DAS mailbox remains the per-cell obs update path: column,index,label.
- studythresholds.csv is the FCS-style numeric threshold store: marker x ROI.
- When both mailbox and threshold_store are present, saving a threshold should attempt both outputs.
- The standalone script touches only the playground/input/output paths it is given.
- The playground Phase 1 contract is strict: Nuclei_*.csv ObjectNumber must match label_*.tif labels.
