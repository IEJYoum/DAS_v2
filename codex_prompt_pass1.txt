WHAT THE SCRIPT MUST DO
-----------------------

The script has one entry point:

    def run(input_root, output_root):
        """Build a spatial HTML viewer from CellProfiler output. Returns viewer_data dict."""

It calls helper functions in this order:

1. discover_roi_datasets(input_root) → list of dicts
   - Glob for Nuclei_*.csv in input_root.
   - For each, infer roi_id and slide_scene from the filename.
     Nuclei_40442ROI01.csv → roi_id="Nuclei_40442ROI01", slide_scene="40442ROI01"
   - Find the matching ROI## subfolder (case-insensitive).
   - Find exactly one label_*.tif in that folder.
   - Find channel TIFFs: all *.tif in that folder EXCLUDING label_*.tif
     and Tiff_*.tiff (the multichannel composite).
   - Return list of dicts:
     {
       "roi_id": "Nuclei_40442ROI01",
       "slide_scene": "40442ROI01",
       "nuclei_csv": Path("Z:/.../Nuclei_40442ROI01.csv"),
       "label_tif": Path("Z:/.../ROI01/label_Nuclei_40442ROI01.tif"),
       "channel_tifs": [Path("Z:/.../ROI01/V_reg_ASMA_ROI01.tif"), ...],
       "roi_folder": Path("Z:/.../ROI01"),
     }
   - Raise ValueError if zero datasets found.
   - Print summary: N datasets found, with roi_ids.

2. build_triplet(dataset_dict) → (df, obs, dfxy)
   - Read the Nuclei CSV.
   - df: columns = markers extracted from Intensity_MeanIntensity_* columns.
     Rename by stripping the prefix: Intensity_MeanIntensity_ASMA → ASMA.
   - obs: columns = slide_scene, roi_id, ObjectNumber, Number_Object_Number,
     AreaShape_Area, seg_label (copy of ObjectNumber), cellid.
     cellid = f"{slide_scene}_cell{ObjectNumber}"
   - dfxy: columns = Location_Center_X, Location_Center_Y.
     (If DAPI_X/DAPI_Y exist, use those instead.)
   - index for ALL THREE frames: cellid values (must be unique).
   - Validate: len(df) == len(obs) == len(dfxy), index is unique.
   - Print summary: N cells, M markers, XY column names.

3. validate_label_overlap(dataset_dict, obs) → overlap_count
   - Open label_tif with PIL/tifffile.
   - Get unique nonzero labels from the TIFF.
   - Compare to set(obs["ObjectNumber"].astype(int)).
   - Print: N labels in TIFF, M ObjectNumbers in CSV, K overlap.
   - Raise ValueError if overlap is zero.
   - Return overlap count.

4. build_catalog_for_dataset(dataset_dict, df, obs, dfxy, output_root) → catalog dict
   - Determine core name: use parse_core_series convention.
     slide_scene "40442ROI01" → core "A1" (ROI number becomes A+number).
     Implementation: int(re.search(r"ROI0*(\d+)", slide_scene).group(1))
     then core_name = "A" + str(that_int).
   - Build the catalog dict (this is the critical contract):

     catalog = {

         "viewer_filename_base": slide_scene,
         "run_name_hint": roi_id,
         "core_tiles": {
             core_name: [
                 {
                     "tile_kind": "composite",
                     "core": core_name,
                     "label": core_name,
                     "asset_type_id": "composite:tiff_stack",
                     "asset_type_label": "Composite (channel-selectable)",
                     "tiff_paths": [str(p) for p in channel_tifs],
                     "overlay_paths": [str(label_tif)],
                     "figure_path": None,
                     "source_paths": [str(p) for p in channel_tifs] + [str(label_tif)],
                 }
             ],
         },
         "roi_data": {},       # filled below
         "roi_mailbox": {},
         "subset_options": {},
         "subset_overlays": {},
         "overlay_backend": {},
         "core_meta": {},
         "groupings": {},
         "view_sets": [],
         "default_view_id": "",
         "asset_type_catalog": {},
     }

   - Build roi_data using the EXISTING function:

     fake_seed = {"core_tiles": catalog["core_tiles"]}
     roi_data = build_roi_data_for_seed(fake_seed, obs, dfxy, df=df, out_root=str(output_root))
   - Validate roi_data is not empty. If empty, raise ValueError with
     diagnostic info (core_name, slide_scene, obs.slide_scene.unique()).
   - catalog["roi_data"] = roi_data
   - Print summary: core_name, N cells in roi_data, has_expression_data.

5. build_viewer(catalog, output_root) → viewer_data
   - from visualization.visu_html_functions7 import build_catalog
   - viewer_data = build_catalog(catalog, outdir=str(output_root))
   - Print: viewer written to output_root.

CORE NAME ↔ SLIDE_SCENE MATCHING
---------------------------------

This is the trickiest seam. Here's how the existing code resolves it:

1. seed_core_slide_scene_map() extracts slide_scene from source_paths
   using extract_slide_scene_from_path(). For playground paths like
   Z:/.../Thresholding_Example/ROI01/V_reg_ASMA_ROI01.tif, this
   returns "ROI01" (no numeric parent folder for slide ID).

2. obs["slide_scene"] will be "40442ROI01" (from Nuclei CSV filename).

3. build_core_position_index() first tries slide_scene match:
   slide_scene_array == "ROI01" → 0 hits (obs has "40442ROI01").
   Then falls back to core_array == "A1" → works, because
   parse_core_series("40442ROI01") → A1.

This fallback works correctly. Do NOT try to fix the mismatch by
changing obs["slide_scene"] to "ROI01" — preserve the real value.
The fallback is the designed behavior for this folder layout.
